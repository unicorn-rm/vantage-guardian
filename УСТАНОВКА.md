# VANTAGE GUARDIAN — установка

Клиент сетевой защиты для машин компьютерного клуба. Windows 10/11, 64 бита.

## Что скачивать

| Файл | Кому |
|---|---|
| `vantage-guardian_0.1.0_x64-setup.exe` | обычная установка на одну машину |
| `vantage-guardian_0.1.0_x64_en-US.msi` | развёртывание на зал: тихая установка, групповые политики |

Оба файла ставят одно и то же. Выбор только в способе установки.

## Проверить, что файл не подменён

Рядом лежит `SHA256SUMS.txt`. В PowerShell:

```powershell
Get-FileHash .\vantage-guardian_0.1.0_x64-setup.exe -Algorithm SHA256 | Format-List
```

Строка `Hash` обязана совпасть с той, что в `SHA256SUMS.txt`. Не совпала — файл
скачался не полностью или подменён; не запускайте.

## Установка на одну машину

Запустить `vantage-guardian_0.1.0_x64-setup.exe` и пройти мастер. Клиент встанет
в `Program Files`, заведёт ярлык и значок в трее.

Windows может показать «Неизвестный издатель»: сборка пока не подписана
сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Установка на зал (тихая)

```powershell
msiexec /i vantage-guardian_0.1.0_x64_en-US.msi /quiet /norestart
```

Удаление:

```powershell
msiexec /x vantage-guardian_0.1.0_x64_en-US.msi /quiet /norestart
```

## Настройка клуба — обязательный шаг

**Установщик не содержит клубного токена, и это сделано намеренно.** Файл можно
выкладывать открыто: в нём нет ни одного секрета — проверено поиском по бинарю
перед выпуском. Без токена клиент запустится и честно скажет, что не настроен.

Токен и клуб задаются переменными окружения машины (не пользователя):

```powershell
[Environment]::SetEnvironmentVariable('COLIZEUM_CLUB', '<идентификатор клуба>', 'Machine')
[Environment]::SetEnvironmentVariable('COLIZEUM_CLUB_TOKEN', '<токен клуба>', 'Machine')
```

Токен выдаёт администратор. После установки переменных клиент нужно перезапустить.

Необязательная переменная — адрес управляющего сервера, если он не по умолчанию:

```powershell
[Environment]::SetEnvironmentVariable('COLIZEUM_CONTROL_URL', 'https://<адрес>/api/v1', 'Machine')
```

## Что клиент делает на машине

- ставит виртуальный сетевой адаптер (Wintun) и запускает демона AmneziaWG
  **скрыто**, без окна консоли;
- заворачивает в туннель выбранные игры и сервисы либо весь трафик — по
  переключателю в окне;
- **не трогает локальные сети клуба**: iSCSI, LANGAME и всё, что живёт в
  `10.*`, `172.16–31.*`, `192.168.*`, идёт мимо туннеля. Диск с играми не уедет
  в туннель ни при каких настройках;
- пишет журнал в `%LOCALAPPDATA%\ru.colizeum.vpn\bin\colizeum-tunnel.log`.

Права администратора нужны: без них не создать сетевой адаптер.

## Если что-то пошло не так

Журнал — первое, что нужно приложить к обращению:

```powershell
Get-Content "$env:LOCALAPPDATA\ru.colizeum.vpn\bin\colizeum-tunnel.log" -Tail 200
```
