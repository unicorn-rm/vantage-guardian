# VANTAGE GUARDIAN

Сетевая защита для компьютерных клубов: заворачивает игровой трафик машины в
собственный туннель, оставляя локальную сеть зала нетронутой.

**[Скачать последнюю версию](../../releases/latest)**

## Что это

Клиент для Windows, который ставится на машины клуба и поднимает туннель
AmneziaWG до узла клуба. Гость видит одно окно: подключиться, выбрать режим,
запустить игру.

- **Раздельный режим** — в туннель уходят только выбранные игры и сервисы,
  остальное идёт напрямую.
- **Полный режим** — весь трафик машины, кроме локальных сетей клуба.
- **Локальные сети клуба не трогаются никогда.** iSCSI с играми, LANGAME и всё,
  что живёт в `10.*`, `172.16–31.*`, `192.168.*`, идёт мимо туннеля при любых
  настройках. Диск с играми не уедет в туннель.
- Клиент показывает только измеренные числа. Где данных нет — стоит прочерк, а
  не правдоподобная цифра.

## Установка

Инструкция целиком — [УСТАНОВКА.md](УСТАНОВКА.md). Коротко:

| Файл | Кому |
|---|---|
| `…-setup.exe` | установка на одну машину |
| `…_x64_en-US.msi` | тихая установка на зал |

Клубный токен в установщик **не входит** и задаётся переменной окружения машины:
файлы можно раздавать открыто, в них нет ни одного секрета.

## Требования

Windows 10/11 x64, права администратора (без них не создать сетевой адаптер).

## Проверка загруженного файла

К каждому выпуску приложен `SHA256SUMS.txt`:

```powershell
Get-FileHash .\vantage-guardian_0.1.0_x64-setup.exe -Algorithm SHA256 | Format-List
```
