# VANTAGE GUARDIAN 0.1.0

Первый собранный установщик. Сборка из коммита `6d5b0f7`, проверена CI:
513 тестов ядра, 136 тестов интерфейса, clippy без предупреждений.

## Туннель

- **Подъём только по кнопке.** Клиент больше не поднимает туннель сам при
  запуске: файл помнит выбор режима и отмеченные цели, но не факт того, что в
  прошлый раз защита была включена. Выбор режима туннель тоже не поднимает.
- **Снята проверка адреса на дубликат (DAD).** Из-за неё адрес интерфейса
  оставался в состоянии `Tentative`, а с такого адреса Windows молча
  выбрасывает исходящие пакеты. Это и была причина «рукопожатие есть, трафика
  нет» на повторных подключениях.
- **Адрес не встал — заводится новый адаптер.** После остановки туннеля Windows
  несколько секунд перенастраивает интерфейс и не даёт удержать на нём адрес.
  Ожиданием это не лечится; клиент делает то же, что раньше делал человек,
  перезапуская программу, — заводит новый адаптер. Ровно один раз.
- **Демон AmneziaWG запускается скрыто.** Чёрное окно консоли больше не
  выскакивает поверх игры.

## Экран

- Главная собрана по фирменному эталону: страж в центре, светящиеся кольца
  позади, фон — вид из космоса на ночную Землю.
- Полоса состояния над героем, карточка узла, блок протокола, карточка «Защита
  сети». Все числа настоящие: где данных нет, стоит прочерк, а не правдоподобная
  цифра.
- Размер окна закреплён 1480×900.
- Раздел «Популярные игры» с обложками и кнопкой запуска.

## Установка

См. `УСТАНОВКА.md`. Коротко: `-setup.exe` для одной машины, `.msi` для тихой
установки на зал, клубный токен задаётся переменной окружения и в установщик
не входит.

## Проверка файлов

`SHA256SUMS.txt` рядом.

## Чего в этой сборке ещё нет

- подписи сертификатом издателя — Windows покажет «Неизвестный издатель»;
- автообновления: новую версию ставят поверх старой вручную.
